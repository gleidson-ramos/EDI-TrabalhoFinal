# 📋 Gerenciamento de Clientes
O projeto implementa um cadastro de clientes utilizando struct, alocação dinâmica de memória, operações de CRUD e persistência de dados em arquivo.

O sistema permite cadastrar e gerenciar clientes por meio de um menu executado no terminal armazenado os dados dinamicamente em memória e permitindo salvar em um arquivo de texto para que sejam recuperados posteriormente.

O código utiliza recursos e bibliotecas da linguagem C, como stdio.h, stdlib.h, struct, malloc, realloc e free.


## ✨ Funcionalidades
O programa está dividido em funções responsáveis por diferentes operações:

| Função | Responsabilidade |
| --- | --- |
| main() | Controla o menu principal |
| cadastrar() | Adiciona um novo cliente |
| exibir() | Lista todos os clientes |
| funcaoIndex() | Localiza um cliente pelo código |
| consultar() | Consulta um cliente |
| editar() | Altera os dados de um cliente |
| deletar() | Remove um cliente |
| salvarArquivo() | Salva os dados em clientes.txt |
| carregarArquivo() | Carrega os dados do arquivo |

## 📄 Sobre o Projeto
Sistema de gerenciamento de clientes desenvolvido em C como trabalho final da disciplina de Estrutura de Dados I.
